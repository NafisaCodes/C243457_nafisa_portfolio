NAFISA TASMIM — PORTFOLIO WEBSITE

FILES
- index.html: Home page
- about.html: About page
- skills.html: Skills page
- projects.html: Projects page
- education.html: Education page
- contact.html: Contact page
- css/style.css: Custom pink theme and responsive styles
- js/script.js: Navigation highlighting, year, and contact form validation

HOW TO RUN
1. Extract nafisa_portfolio.zip to a folder.
2. Open Visual Studio Code.
3. Select File > Open Folder and choose nafisa_portfolio.
4. Install the Live Server extension if you do not already have it.
5. Right-click index.html and choose Open with Live Server.
6. Use the navbar to open all six pages.

IMPORTANT BEFORE SUBMISSION
- Replace the sample email with your real academic/contact email if appropriate.
- Update education institute names and dates with your real details.
- Adjust skill percentages honestly.
- Replace sample project descriptions with projects you have actually completed.
- The avatar is an emoji illustration placeholder. You can add images/avatar.png and replace the emoji element with <img src="images/avatar.png" alt="Illustrated avatar" class="img-fluid">.
- Bootstrap and Google Fonts use internet CDNs, so internet is needed for those resources.
- The contact form is front-end only; it validates but does not send email without a backend/service.
